# stepwise Vite starter

The smallest real app on [`@sphynxoid/stepwise`](https://www.npmjs.com/package/@sphynxoid/stepwise),
installed from npm with no Tailwind: a bubble-sort trace in a `PlayerBar`
plus a two-step guided tour, styled by the precompiled `styles.css`.

```bash
npm install
npm run dev
```

[Open in StackBlitz](https://stackblitz.com/github/TheSphynxoid/stepwise/tree/master/examples/vite-starter)
